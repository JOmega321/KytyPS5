# Blue soul wisp

`demons-souls-kyty.png` is the application icon for Demon's Souls (KyTy).
It was created for this fork with the built-in image-generation tool. The
generated 1280x1280 artwork was resized to 512x512 for desktop integration;
the opaque black background and artwork are otherwise unchanged. It is original
generated artwork, not a game asset or an official Sony/Bluepoint logo.
